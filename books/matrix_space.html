矩阵空间

把所有 m×n 矩阵放进一个集合，加法与数乘让它变成一个向量空间——这就是矩阵空间。本文从定义出发，逐步搭建基、维度、子空间与内积结构，并提供一个可交互的基分解实验台。

$$M_{m\times n}(\mathbb{R}) = \left\{ A = (a_{ij}) \;\middle|\; a_{ij}\in\mathbb{R},\; 1\le i\le m,\; 1\le j\le n \right\}$$
01

什么是矩阵空间

给定域 ℝ（或任意域 𝔽），所有 m×n 实矩阵构成的集合，配上矩阵加法与标量乘法，就是一个向量空间——记作 M_{m×n}(ℝ)，简称矩阵空间。

运算定义。对任意 $A=(a_{ij}),\,B=(b_{ij})\in M_{m\times n}$ 与标量 $k\in\mathbb{R}$：

$$(A+B)_{ij} = a_{ij}+b_{ij}, \qquad (kA)_{ij} = k\,a_{ij}$$

也就是说，矩阵的加法和数乘都是逐元素进行的——这与向量 $\mathbb{R}^n$ 中坐标分量的运算完全同构。事实上 $M_{m\times n}(\mathbb{R})$ 与 $\mathbb{R}^{mn}$ 作为向量空间是同构的，只是把 $mn$ 个数排成了矩形而不是一列。

直观理解 把矩阵想象成一张 m 行 n 列的"格子纸"，每个格子里填一个数。矩阵空间就是所有可能填法的集合；两张格子纸对应相加，就是把每个格子里的数分别相加。
02

验证向量空间八条公理

要确认 $M_{m\times n}(\mathbb{R})$ 真的是向量空间，需要逐条核对向量空间公理。因为矩阵运算是逐元素定义的，而实数满足这些性质，所以每一条都自动继承。

✓加法交换律：$A+B=B+A$
✓加法结合律：$(A+B)+C=A+(B+C)$
✓零元存在：零矩阵 $O$ 满足 $A+O=A$
✓负元存在：$A+(-A)=O$
✓数乘结合律：$k(lA)=(kl)A$
✓单位数乘：$1\cdot A = A$
✓数乘对加法分配：$k(A+B)=kA+kB$
✓数乘对标量加法分配：$(k+l)A=kA+lA$
03

标准基与维度

定义基本矩阵 $E_{ij}$：第 $i$ 行第 $j$ 列为 1，其余全为 0。这 $mn$ 个矩阵构成 $M_{m\times n}(\mathbb{R})$ 的一组基，称为标准基。

$$\dim M_{m\times n}(\mathbb{R}) = m \times n$$

任意矩阵 $A=(a_{ij})$ 都能唯一地写成标准基的线性组合：

$$A = \sum_{i=1}^{m}\sum_{j=1}^{n} a_{ij}\, E_{ij}$$

05

常见子空间

矩阵空间内部藏着许多重要的线性子空间，它们各自的维度反映了约束条件"用掉"了多少自由度（以 $n\times n$ 方阵为例）。

dim = n(n+1)/2

对称矩阵

满足 $A^{T}=A$，即 $a_{ij}=a_{ji}$。上三角（含对角线）的每个位置可自由取值，其余由对称性决定。

dim = n(n−1)/2

反对称矩阵

满足 $A^{T}=-A$，对角线元素必为 0，$a_{ij}=-a_{ji}$。任意方阵可唯一分解为对称部分 + 反对称部分。

dim = n(n+1)/2

上三角矩阵

主对角线及以上元素任意，以下全为 0。下三角矩阵同理，维度相同但两者不是同一子空间。

dim = n

对角矩阵

只有主对角线可以非零，是上三角与下三角矩阵子空间的交集，维度最小、结构最"简单"。

dim = n² − 1

迹为零矩阵

$\operatorname{tr}(A)=\sum a_{ii}=0$，是一个线性方程，恰好削去一个自由度——这也是李代数 $\mathfrak{sl}(n)$ 的载体。

dim = n²

全空间 M(n×n)

不加任何约束的全体方阵集合，是以上所有子空间共同的"母空间"。

直和分解 对称矩阵与反对称矩阵这两个子空间除了零矩阵外没有任何交集，且合在一起能"拼满"整个方阵空间——这正是直和的定义：$M_{n\times n}(\mathbb{R}) = \text{Sym}(n) \oplus \text{Skew}(n)$。维度上也严丝合缝：$\dfrac{n(n+1)}{2} + \dfrac{n(n-1)}{2} = n^2$。任意方阵 $A$ 都能唯一拆成 $A=\underbrace{\tfrac12(A+A^{T})}_{\text{对称部分}} + \underbrace{\tfrac12(A-A^{T})}_{\text{反对称部分}}$。
06

Frobenius 内积与范数

给矩阵空间装上内积结构，就能谈论"矩阵之间的角度"与"矩阵的长度"，这就是 Frobenius 内积。

$$\langle A, B \rangle_F = \operatorname{tr}(A^{T}B) = \sum_{i=1}^{m}\sum_{j=1}^{n} a_{ij}\,b_{ij}$$

诱导出的范数为

$$\|A\|_F = \sqrt{\langle A,A\rangle_F} = \sqrt{\sum_{i,j} a_{ij}^{2}}$$

这正是把矩阵"拉直"成 $\mathbb{R}^{mn}$ 中的向量后所用的标准欧氏内积——标准基 $\{E_{ij}\}$ 在此内积下彼此正交，且每个 $E_{ij}$ 的范数为 1，因此它是一组标准正交基。

07

矩阵的四大基本子空间

和前面说的"矩阵空间"这个大容器不同，这里指的是某一个具体矩阵 $A\in\mathbb{R}^{m\times n}$（设 $\operatorname{rank}(A)=r$）自身诱导出的四个子空间——线性代数里最著名的"大图景"（The Big Picture）。

极简对比法则
$$\underbrace{N(A)}_{\text{看输入}} \quad \xrightarrow{\ A_{m\times n}\ } \quad \underbrace{C(A)}_{\text{看输出}}$$
输入端 ℝⁿ · 看输入
  • 行空间 Row(A) — 输入端里"能被 $A$ 有效映射"的向量：经过 $A$ 之后不会变成 0。
  • 零空间 N(A) — 输入端里"被 $A$ 抹杀"的向量：经过 $A$ 之后全部变成 0。
输出端 ℝᵐ · 看输出
  • 列空间 C(A) — 输出端里"真正能被生成"的区域：矩阵所有列向量投射出的实际幕布。
  • 左零空间 N(Aᵀ) — 输出端里"绝对触碰不到"的死角：矩阵无论如何也映射不到的地方。
零看输入，列看输出。
dim = r⊂ ℝⁿ

行空间 Row Space

$C(A^{T})$，由 $A$ 的所有行向量张成，等价于行最简形中非零行张成的空间。

→ 有效信号区域：能被 $A$ 成功转换、对输出真正有贡献的那部分输入。

dim = n − r⊂ ℝⁿ

零空间 Null Space

$N(A)=\{x\in\mathbb{R}^n : Ax=0\}$，即齐次线性方程组 $Ax=0$ 的全部解。

→ 零值化死角：被矩阵直接压扁蒸发、对输出毫无贡献的那部分输入。

dim = r⊂ ℝᵐ

列空间 Column Space

$C(A)$，由 $A$ 的所有列向量张成，也是线性映射 $x\mapsto Ax$ 的值域。

→ 实际可达区域：矩阵无论怎么变换输入，真正能生成的全部输出。

dim = m − r⊂ ℝᵐ

左零空间 Left Null Space

$N(A^{T})=\{y\in\mathbb{R}^m : A^{T}y=0\}$，等价于 $y^{T}A=0$ 的全部解。

→ 不可达残差死角：理论上无论如何也生成不出来的输出盲区。

四大子空间"住"在哪里 容易搞混的一点：这四个子空间并不藏在矩阵 $A$ 内部，而是矩阵把输入空间 $\mathbb{R}^n$ 和输出空间 $\mathbb{R}^m$ 各自切出的两块"专属领地"。任意输入向量都能唯一拆成 $x = x_{\text{行}} + x_{\text{零}}$：$x_{\text{零}}$ 这部分会被 $A$ 直接压成 0，只有 $x_{\text{行}}$ 真正"活着"传到输出端。对应地，任意输出向量也能唯一拆成 $b = b_{\text{列}} + b_{\text{左零}}$——当方程 $Ax=b$ 无解时，$b_{\text{左零}}$ 正是"实际测量值"与"理论可达值"之间那部分怎么都补不上的残差，也正是最小二乘法要设法压到最小的那块东西。
正交关系（秩-零化度定理） 行空间与零空间在 $\mathbb{R}^n$ 中互为正交补：$\mathbb{R}^n = C(A^{T}) \oplus N(A)$，维度满足 $r+(n-r)=n$。同理，列空间与左零空间在 $\mathbb{R}^m$ 中互为正交补：$\mathbb{R}^m = C(A) \oplus N(A^{T})$，维度满足 $r+(m-r)=m$。

$A$ 把输入端 $\mathbb{R}^n$ 里"活着"的行空间一一映射（同构）到输出端 $\mathbb{R}^m$ 的列空间，同时把输入端"死掉"的零空间整体压扁到原点。

08

矩阵空间上的线性变换

别忘了矩阵空间本身也是一个向量空间——所以完全可以在它上面定义线性映射。这里挑两个最常见的例子，正好和前面讲过的内容对上号。

线性同构

转置 A ↦ Aᵀ

$T:M_{m\times n}\to M_{n\times m}$，$T(A)=A^{T}$。满足 $T(A+B)=T(A)+T(B)$、$T(kA)=kT(A)$，是线性映射；又因为 $T\circ T=\mathrm{id}$，$T$ 是双射，所以它是一个线性同构——$M_{m\times n}$ 与 $M_{n\times m}$ 维度相同（都是 $mn$），结构上"长得一样"。

线性泛函

迹 A ↦ tr(A)

$\operatorname{tr}:M_{n\times n}\to\mathbb{R}$，$\operatorname{tr}(A)=\sum_i a_{ii}$。这是一个把矩阵"吃进去、吐出一个数"的线性泛函。它的核 $\ker(\operatorname{tr})=\{A:\operatorname{tr}(A)=0\}$ 正是第 05 节提到的迹为零子空间，维度 $n^2-1$。

换个角度看四大空间 第 07 节的"四大空间"其实是矩阵 $A$ 作为线性映射 $x\mapsto Ax:\mathbb{R}^n\to\mathbb{R}^m$ 诱导出的核与像；而这里的转置、迹，是把矩阵本身当作向量，在矩阵空间 $M_{m\times n}$ 上定义新的线性映射，并且迹映射同样满足秩-零化度定理：$\dim M_{n\times n} = \dim\ker(\operatorname{tr}) + \dim\operatorname{im}(\operatorname{tr}) = (n^2-1)+1$。同一套"核（被压扁的）/ 像（能生成的）"语言，可以套用在任何线性映射上——这正是线性代数最值钱的抽象。
09

例题

01

设 $A\in\mathbb{R}^{4\times5}$，$\operatorname{rank}(A)=3$。求零空间与左零空间的维度。

查看解答
解：dim 零空间 = n − r = 5 − 3 = 2；dim 左零空间 = m − r = 4 − 3 = 1。
02

求 $M_{2\times2}(\mathbb{R})$ 中满足 $a_{11}+a_{22}=0$ 的子空间的维度。

查看解答
解：这是迹为零的 2×2 矩阵，约束削去 1 个自由度，dim = 4 − 1 = 3。
03

证明任意方阵 $A$ 可唯一写成对称矩阵与反对称矩阵之和。

查看解答
解：令 $A_s=\tfrac12(A+A^{T})$，$A_a=\tfrac12(A-A^{T})$，则 $A_s$ 对称、$A_a$ 反对称，且 $A=A_s+A_a$；唯一性由两子空间仅交于零矩阵得出，即 $M_{n\times n}=\text{Sym}\oplus\text{Skew}$。
04

验证标准基向量 $E_{12}$ 与 $E_{21}$ 在 Frobenius 内积下正交。

查看解答
解：$\langle E_{12},E_{21}\rangle_F=\sum_{i,j}(E_{12})_{ij}(E_{21})_{ij}=0$，因为两者非零位置不重合。
05

设 $\operatorname{tr}:M_{3\times3}(\mathbb{R})\to\mathbb{R}$ 为迹映射。它的像 $\operatorname{im}(\operatorname{tr})$ 是什么？由此验证秩-零化度定理。

查看解答
解：迹映射不是零映射（例如单位阵 $I$ 的迹为 3 ≠ 0），且值域是 $\mathbb{R}$ 的子空间，只能是 $\{0\}$ 或 $\mathbb{R}$ 本身，故 $\operatorname{im}(\operatorname{tr})=\mathbb{R}$，dim = 1。核（迹为零矩阵）维度是 $3^2-1=8$。验证：$\dim\ker+\dim\operatorname{im}=8+1=9=\dim M_{3\times3}$，与秩-零化度定理吻合。
06

方程 $Ax=b$ 无解，用最小二乘法求出的最优解 $\hat{x}$ 满足 $A^{T}(b-A\hat{x})=0$。说明残差向量 $r=b-A\hat{x}$ 恰好落在左零空间 $N(A^{T})$ 中，并解释这为什么等价于"残差与列空间正交"。

查看解答
解：$A^{T}r=A^{T}(b-A\hat{x})=0$，这正是左零空间 $N(A^{T})=\{y\in\mathbb{R}^m:A^{T}y=0\}$ 的定义式，所以 $r\in N(A^{T})$。又因为 $C(A)=N(A^{T})^{\perp}$（第 07 节的正交关系），$r\in N(A^{T})$ 就等价于 $r\perp C(A)$——也就是说最优残差必须与整个列空间垂直，这正是最小二乘法"投影求解"的几何本质：$A\hat{x}$ 是 $b$ 在列空间上的正交投影，多出来的那部分残差被甩进了列空间够不着的左零空间死角里。
